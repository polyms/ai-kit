# Research

Use [research-template.md](research-template.md) and the shared work artifact standard
(`docs/agents/work-artifact-standard.md`).

Use [evidence-guide.md](evidence-guide.md) for source audits, comparisons, knowledge search and digests.

1. State the question, intended decision, scope, time window and inclusion criteria.
2. Discover relevant sources with available web, repository or workspace tools. Prefer primary sources;
   for contested claims, compare independent sources. Respect access boundaries.
3. Read the actual evidence, verify dates and check whether claims support the question. Cross-check
   consequential disputed claims using independent evidence, or disclose the gap.
4. Synthesize findings by topic rather than listing links. Separate evidence, inference and uncertainty.
5. Compare options on consistent criteria if the question is comparative.
6. Cite real accessible source links close to claims; include publication or event dates when relevant.
7. Provide implications and practical next steps, and state gaps or limitations.

If search is unavailable, disclose the limitation and do not fabricate citations or imply completed research.
