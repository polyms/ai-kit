# Bug

Use [bug-template.md](bug-template.md) and the shared work artifact standard
(`docs/agents/work-artifact-standard.md`).

1. Capture the observed symptom, affected feature, environment, preconditions and evidence as supplied.
2. Identify the expected behavior and its source. If uncertain, label it as proposed or unknown.
3. Write numbered reproduction steps. Do not claim reproduction or root cause unless actually verified.
4. Describe impact and frequency separately. Distinguish severity (impact) from priority (urgency).
5. Where possible, search existing issues and link a likely duplicate. Do not close or alter other issues.
6. Use the template; define testable fix acceptance criteria, including regression coverage when applicable.
7. Apply the shared quality check. Publish only when requested; return the actual issue ID and URL.

If evidence is incomplete but a report is requested, produce a useful draft and mark missing information.
Do not invent logs, screenshots, versions, severity, reproduction results or affected user counts.
