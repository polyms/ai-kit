# Align Loop

Interview relentlessly until shared understanding. Walk each branch of the decision tree; resolve dependencies one-by-one.

## Steps

1. Confirm problem statement before any solution branches — restate in one paragraph; ask user to confirm or correct

   **Completion criterion:** User confirms or corrects the problem statement.

2. Walk each decision branch — dependencies first

   **Completion criterion:** Decision tree mapped; dependencies ordered.

3. For each question:
   - Provide your **recommended answer**
   - Wait for user feedback before continuing
   - If answerable from codebase, explore code instead of asking

   **Completion criterion:** Current branch resolved before opening the next question.

4. Flag unresolved risks and assumptions explicitly

   **Completion criterion:** Every unresolved risk or assumption is named.

5. Summarize decisions as a bullet list

   **Completion criterion:** User confirms the summary; no open decision branches remain.
