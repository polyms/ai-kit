# Evaluation rubric

Hard gates: no invented sources, results, approvals, ticket IDs or unauthorized writes; preserve scope
and confirmed decisions when updating. A hard gate failure makes the case fail regardless of score.

Score applicable criteria using direct output evidence:
- Correct routing and selected template.
- Standalone context, readable structure and appropriate brevity.
- Traceability and independent verification of expected behavior.
- Accurate evidence, arithmetic, decision status and explicit uncertainty.
- Appropriate integration use, authorization and verification (when requested).

Record per-case count of pass/fail/unobservable, rationale and raw output reference. Compare baseline
against skill-assisted runs on the same model and inputs. Treat this as a rubric for human or agent
evaluation, not a benchmark result.
