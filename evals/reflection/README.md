# Reflection and Knowledge Contribution scenarios

These fifteen synthetic manual host-client scenarios exercise optional reflection, evidence integrity,
duplicate avoidance, privacy, scope, approval, and publication receipts. They do not require real
Knowledge writes or actual credentials. Use simulated search/read results, admin authority and
receipts; never publish a fixture. Use the selected live skill, portable standard and conditional
reflection protocol. Record the result, calls (including zero calls when expected), actual
disposition and forbidden behavior; a human reviews semantic outcomes.

The existing skill-pack tests validate fixture shape and selective reference delivery. These are
not integrated into the paid paired evaluation runner, and structural checks are not measured
model behavior. No model evaluation or client compatibility claim follows from a passing fixture
test. Reuse the same fixture in each host tested.
